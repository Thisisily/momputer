### Your agents never clean up. Mom does.

AI agents start dev servers, watchers and headless browsers, and nobody turns them off. A week later seventy copies of `node` are still running and your disk is full of scratch folders.

**momputer** knows which agent started what, shows you what was left behind, and cleans it up, after showing you exactly what she's about to do. And since she's in the house anyway, she looks after the rest of your computer too.

- **One press** turns off everything your agents left running.
- **Nothing goes unseen**: she shows you what it is first, then you confirm.
- **Nothing leaves your computer**. She only asks the internet whether there's a newer mom.
- **A small widget** when you want her out of the way, **BIG MODE** when you want the whole picture.

## Install

### On Windows

**[Download for Windows](https://thisisily.github.io/momputer/)**: one button, three steps.

It isn't code-signed yet, so Windows warns that it's from an unknown publisher. Choose **More info**, then **Run anyway**.

Mom lives by the clock. Click her for the widget. The arrows in its title bar are BIG MODE. When a newer version is out, a red light shows on the "i", with the button to get it.

<details>
<summary>Build it from source</summary>

```powershell
git clone https://github.com/thisisily/momputer
cd momputer
.\scripts\build.ps1
```

You need Rust 1.95+, the MSVC build tools and WebView2 (already on Windows 11). The script builds `mom.exe` and the installer (`target\release\bundle\`). To try it without installing:

```powershell
cargo build --release -p mom-cli -p momputer
.\target\release\momputer.exe
```

Run from a folder of your own like this, it all works except the clean-ups that need an administrator: mom won't ask for one from a folder anything running as you could change.

</details>

### On a Mac

It isn't a download yet (that needs Apple's signing), so build it:

```sh
git clone https://github.com/thisisily/momputer
cd momputer
./scripts/build.sh --app
open target/release/bundle/macos/momputer.app
```

You need Rust 1.95+ and Xcode's command line tools (`xcode-select --install`). Mom lives in the menu bar. Click her for the widget; the red button tucks her away again.

macOS asks before she looks in Downloads, Documents or the Desktop, and before she asks Finder to move an app that belongs to the whole Mac. A copy you built yourself is a new app to macOS each time you build it, so it asks again.

## For your agents

- **The `mom` command**: `mom leftovers`, `mom stop mine`, `mom trash`, `mom pc` and more, with `--json` for scripts. [Every command](docs/in-detail.md#the-mom-command).
- **Hooks**: she checks in before an agent says it's done, and asks it to stop what it started. [How](docs/in-detail.md#give-every-agent-a-mom).
- **Skills**: eleven of them. Tidy your folders, desktop, inbox, calendar, bookmarks and subscriptions, in Claude Code or Codex. They work without momputer. [All of them](skills).
  In Claude Code: `/plugin install momputer-skills --marketplace Thisisily/momputer`. The widget lists them, with what to say, under House rules > Skills, and tells you when your agent's copy is behind.
- **Agent health**: every MCP server, hook and setting your agents have. One button asks Claude Code which of its servers answer and which are waiting for a sign-in. Tap anything to read its file in BIG MODE, with keys blanked. [How](docs/in-detail.md#agent-health).

## What mom will never do

- Delete anything without showing you first. You press, then you confirm.
- Stop the system's own processes, an agent itself, or anything you marked "keep".
- Throw your own files away for good: those go to the Recycle Bin (the Trash, on a Mac).
- Send anything about you or your computer anywhere. The one thing she asks the internet is whether there's a newer version, and you can switch that off.
- Ask for administrator rights from a copy something else could have swapped.

[The full list, and how she knows who left what](docs/in-detail.md#how-mom-knows-who-did-it).

## Code signing

Releases are built from this repository by GitHub Actions and aren't code-signed yet. [How signing is set up](docs/signing.md).

Privacy: momputer sends nothing about you or your computer anywhere. Once a day it asks GitHub whether there's a newer version (the same request from every copy); Settings turns that off.

## Roadmap

- **The rest of the Mac version** (a signed download, the Trash, administrator clean-ups), then Linux.
- **Out of date**: which apps and global packages (winget, npm, pip, uv, cargo, scoop, Chocolatey) have a newer version, and one button to update them.
- **Known holes**: a vulnerability checker for versions with known security problems, the ones attackers already use first.
- **winget**: install momputer with one command.
- **An MCP server**, so agents can ask mom directly.
- **More mom**: bedtime (a nightly tidy-up), screen time for agents, a nudge when a disk is nearly full.

How each one would work: [docs/roadmap.md](docs/roadmap.md).
